Migrating from legacy tools

Looking for an iTunes alternative, or moving on from gtkpod, YamiPod, CopyPod, EphPod, Strawberry, or Clementine? Here is what to expect from iOpenPod 2.

Start with the iPod you have

Browse the existing library on a supported iPod. Keep a Backup Snapshot before making changes, then choose the media you want to add. Direct import of another manager’s database or settings is not promised.

No libgpod dependency

iOpenPod 2 uses its own Python iPodDB engine to read and write iPod databases. It does not require libgpod. Device-specific compatibility is still being validated.

Free and open source

iOpenPod 2 is free software for Windows, macOS, and Linux under GPL-3.0-or-later. Native builds, PyPI, and store releases are planned; check download availability for each channel.

Review before you sync

See additions, updates, and removals in Sync Review. Removal candidates start unchecked. Backup Snapshots are user-controlled, and interrupted writes have an explicit recovery workflow.
