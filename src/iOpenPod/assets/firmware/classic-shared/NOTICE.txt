Universal Classic Firmware 2.0.5, Mod Platform Version 0.11.0-dev.

firmware.zlib is the complete device-independent firmware image, compressed
with zlib. It includes the unsigned common OS, resources and directory.
It contains Apple code and resources plus the iOpenPod About/version extension
and the unsigned eapp manifest mod (org.iopenpod.homebrew, 0.1.0-dev).
Extras / Mods lists the twelve included firmware mods using Apple's native UI,
including Expanded Mod Memory (4 MiB RAM budget, 16 MiB OS slot) and
Light / Dark Appearance (0.1.5-dev), with Light, Dark and timed Auto in Settings.
The World Clock row backdrop follows dark appearance; day/night faces and
clock hands keep their original semantics.
Now Playing Preview Artwork (0.1.3-dev) connects the main-menu preview to native
current-track artwork, with a 128 x 128 layout and native no-art fallback.
Dynamic BitmapView contexts are released across visibility changes without
releasing shared artwork pixels or allocating another image cache. Appearance
changes also notify the native playback artwork property, refreshing an attached
preview without requiring a visibility change. The current-track thumbnail is
loaded and retained through Apple's model reference, with native release on
replacement. Drawing uses the actual dynamic bitmap format for Draw/0x7f05,
preventing color artwork from being treated as an icon mask. The user confirmed
correct behavior on 0.6.7. Version 0.6.8 retains those fixes and omits temporary
artwork tracing, pixel sampling and the iOpenPodArtworkTrace USB dictionary.
The developer diagnostic build option remains available in source.
Bootloader Report (0.1.0-dev) measures plaintext NOR at startup and publishes
the marker, complete executable hash and SysCfg identity over native USB.
Its SPI sequence derives from Rockbox 10ec9bd5, norboot-s5l8702.c and
spi-s5l8702.c, Copyright (C) 2009 Michael Sparmann. SHA-256 reuses the
osos-lab implementation distributed under scripts/bootloader/native/vendor.

The independent seek implementation preserves the native wrapper, validates
bounded tables, handles cursor/error-state conventions and checks complete
sample-window reads. See scripts/firmware/classic_about/long_audio.c and
docs/research/classic-long-audio-fixes-2026-11-18.md.
Photo Zoom and Pan (0.3.0-dev) adds wheel zoom and held-button panning in the native photo viewer.
Center enters the mode and pans up while held. Menu resets or exits the mode.
A bottom-right magnifier indicates the active mode at every zoom level.
Magnification uses the native 720 x 480 F1067 I420 cache when available,
falling back to the LCD rendition without allocating a second full-image buffer.
Title Bar Clock (0.1.0-dev) aligns full-width titles to the left and places
local time at the right when Time in Title is enabled.
