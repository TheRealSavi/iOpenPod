# Genius Mix icons

These 22 SVGs are unmodified Tabler Icons outline assets from
[`tabler/tabler-icons`](https://github.com/tabler/tabler-icons) at commit
`a4ce1404bc6d24d3c365afe7b258d6bf6f48d62d`. They are distributed under
the adjacent [MIT license](LICENSE). The application renders them with its
existing `currentColor` glyph provider; no Tabler runtime package is required.
