# Application icon

The creator is **DJShott**, who offered it in a Ko-fi
message for use in future iOpenPod updates. The project owner provided that message
on 2026-09-25. Its permission is recorded in
[`DJShott-icon.txt`](./DJShott-icon.txt). iOpenPod GPL grant do not relicense this separately
contributed artwork. Standalone artwork reuse or a broader open-source license
would require clarification from its creator.

The largest available source is `icon-256.png`; its SHA-256 is
`3cdc1d8d98c707209e415e4824793f71ed1a1c53c541161abee3def3f63a6dbe`.
The packaging script converts these assets to Windows Store tile sizes and ICNS.
Larger macOS representations are upscaled from this source.
