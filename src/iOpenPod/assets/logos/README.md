# Logos

`phase.svg` redraws the five letters in the Phase logo reference supplied by the
user with smooth Bézier curves and consistent strokes. The background and
tagline are omitted. The
wordmark uses `currentColor` and its original wide proportions, rendered through
the shared icon provider in the Phase Playlist hero. It has no font or
embedded raster-image dependency. This is a game wordmark, separate from the
24-pixel navigation glyph collection.
