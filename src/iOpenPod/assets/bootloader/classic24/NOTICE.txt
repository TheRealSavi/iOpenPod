iOpenPod Classic24 bootloader installation assets

Custom native code and host probe port: GPL-3.0-only. Source, rebuild instructions
and upstream provenance are in scripts/bootloader in the iOpenPod source tree.
The source distribution includes the corresponding C, ARM assembly and Go code.

SPI/SST25 sequencing derives from Rockbox 10ec9bd5, norboot-s5l8702.c and
spi-s5l8702.c, Copyright (C) 2009 Michael Sparmann.
DFU certificate-envelope construction follows Rockbox mks5lboot.
SHA-256 and return trampoline derive from osos-lab
d2c8e357d58591bdaa70bb6be9da191f489554a6 (GPL-3.0-only).
Probe encodings derive from osos-lab / wInd3x,
